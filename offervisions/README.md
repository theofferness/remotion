# Offervisions – 30s vertical promo (Remotion)

A 1080×1920, 30 fps, 30-second animated promo for the **Offervisions** self-development podcast.
It uses original glowing line-art motion graphics, typewriter and kinetic headlines, word-by-word captions,
zoom-blur scene transitions, an original music bed with synced sound effects, and a follow/listen call to action.

| # | Scene | Visual |
|---|-------|--------|
| 1 | Hook – *"They never start."* | A figure stares at a dashed staircase it hasn't climbed, with a "someday…" thought |
| 2 | Motivation spike – *"It fades."* | A graph line spikes on Sunday and crashes by Monday |
| 3 | Discipline stairs – *"One step a day."* | The staircase builds step by step as the figure climbs (+1% per step) |
| 4 | Compounding – *"For one year."* | A ring fills while a counter compounds 1.00× → 37.8× |
| 5 | Vision – *"Offer yourself a vision."* | A silhouette raises their arms as a sun rises behind the hill |
| 6 | CTA | Logo, wordmark, a cursor clicks **Follow → Following**, "Listen on" platforms, handle |

## Quick start

```bash
npm install
npm run dev        # opens Remotion Studio to preview and edit
npm run render     # writes out/offervisions.mp4
```

## Changing things – everything is in `src/config.ts`

- **Script / text:** `SCRIPT` has, for each scene, the `kicker` (small serif line), the `headline`
  (wrap a word in `*asterisks*` to colour it with the accent), the `caption` (subtitle line) and `durationSec`.
  The total length updates automatically.
- **Brand / CTA:** `BRAND` holds the name, tagline, handle, platforms and button labels.
- **Colours:** `THEME`: background, glow, ink (lines and text), muted, accent and onAccent.
- **Fonts:** `FONTS` lists the font files in `public/fonts` (Inter and Instrument Serif are bundled, so renders work offline).
  Add your own files there and set `THEME.headlineFont` / `THEME.serifFont`.
- **Audio:** `AUDIO`:
  - `music`: replace `public/audio/music.mp3` with your own track, or point this at another file. `null` turns music off.
  - `voiceover`: e.g. `'audio/voiceover.mp3'`. While it plays, the music is automatically lowered to `musicDuckedVolume`.
  - `sfx` / `sfxVolume` / `sfxEnabled`: whooshes, pops, dings, click and riser.
- **Captions:** they're auto-timed from `SCRIPT` captions. If you record a voiceover, paste word timestamps
  (Remotion `Caption` format) into `CAPTIONS_OVERRIDE` so the captions follow your real voice.
  `FORMAT.showCaptions` / `captionsOnCta` toggle them.
- **Transitions:** set `FORMAT.transitionFrames`; 0 gives hard cuts.

Every one of these values can also be edited live in Remotion Studio's **Props** panel.

The placeholder music and sound effects are original, generated by `npm run audio` (`scripts/generate-audio.mjs`, needs ffmpeg).
